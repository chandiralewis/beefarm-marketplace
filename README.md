# 🐝 BeeFarm Marketplace

A web-based marketplace connecting local bee farmers with customers to purchase bee products online.

## 📌 About the Project

BeeFarm Marketplace is a web application developed as part of the Developing Modern Web Applications (DMW) module at NIBM.

The system provides an online platform where customers can browse bee products, manage their profiles, place orders, and track purchases. Farmers and administrators can manage products, orders, notifications, and sales information.

## 🚀 Features

### Customer
- User Registration & Login
- Browse Products
- Product Details
- Wishlist
- Shopping Cart
- Checkout
- Order Management
- Order Tracking
- Customer Profile
- Notifications

### Farmer / Admin
- Farmer Dashboard
- Add Products
- Manage Products
- Manage Orders
- Order Tracking
- Sales Summary
- Notifications
- Earnings & Reports

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## 🎯 Project Objective

The main objective of BeeFarm Marketplace is to provide a digital platform that makes it easier for bee farmers to showcase and sell their products while providing customers with a convenient online shopping experience.
